# Code of Conduct

## Our standard

This project aims to be a respectful, technically serious, and welcoming place to collaborate. We expect contributors, maintainers, and participants in issues and pull requests to treat each other with patience, clarity, and good faith.

Examples of expected behavior:

- Be respectful in disagreement.
- Focus criticism on code, behavior, evidence, and outcomes.
- Assume mistakes can be corrected.
- Share context that helps others reproduce or understand a problem.
- Be thoughtful about accessibility, inclusion, and the experience of newcomers.

Examples of unacceptable behavior:

- Harassment, intimidation, or personal attacks.
- Insults, slurs, or degrading language.
- Repeated bad-faith argument or deliberately disruptive behavior.
- Publishing private information without permission.
- Dismissing accessibility or safety concerns without technical engagement.

## Scope

This code of conduct applies in repository spaces, including issues, pull requests, reviews, and discussions directly tied to this project.

## How maintainers will respond

Maintainers may edit, hide, lock, or remove content that violates this code of conduct. They may also pause or end participation from accounts that repeatedly or severely violate it.

When reviewing a report or incident, maintainers will try to:

- understand the specific behavior,
- reduce harm to affected participants,
- keep enforcement proportional, and
- protect the project from repeated disruption.

## Reporting

If you experience or witness behavior that violates this code of conduct, open a private moderator-visible channel if GitHub provides one for the relevant surface. If that is not available, open a minimal public issue requesting maintainer attention without reposting harmful material.

## Project values

This repository values:

- evidence over noise,
- accessibility as a product requirement,
- small, reviewable changes,
- clear attribution of risks and tradeoffs,
- and kindness that does not hide important technical truth.
