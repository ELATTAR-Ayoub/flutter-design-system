# Visual direction

Start each UI with a one-sentence concept. Build in order: audience and job, primary action/focal object, reading order and measure, semantic type/color, then at most one supporting effect.

Use `StyledText`/`TextStyles` by role and numeric type for metrics. Use neutral surfaces for structure, the primary color for action, and status colors only for meaning. Repeated content aligns; one value/title owns each section. Effects such as page glow, glass, machine surface, bloom, foil, or starfield must reinforce hierarchy and work in both themes.

For references, inspect actual material first and extract hierarchy, density, type behavior, contrast, material, interaction rhythm, and mood. Assign a role to each reference, never copy its logo, copy, brand, or recognisable full layout. Prefer subtraction over a noisy blend of motifs.
