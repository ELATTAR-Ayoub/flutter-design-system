# Agent-console contract

Treat agent UI as a stateful workbench, not chat decoration. Inspect relevant `ElAgent*` constructors and tests together before composing a surface.

Cover transcript attribution/status and reliable latest-work navigation; multiline composer, keyboard submission, attachments, disabled/running/cancel states; tool running/success/error/approval/retry/result visibility; history confirmation for destructive work; layout-preserving loading; focus restoration after overlays; and visible semantic error/recovery. Use the exported agent family before custom composition. Avoid ambient animation near live output: readable status wins.
