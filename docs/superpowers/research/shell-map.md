## 1. Root layout — `app/layout.tsx`

**Metadata**: title `Elattar's Design System`; description `Foundations, base components and a complete agent console — every token, in light and dark.`

**`<html lang="en" suppressHydrationWarning className="${GeistMono.variable} h-full antialiased">`** — suppressHydrationWarning is required because next-themes writes the resolved theme class onto `<html>` pre-hydration via inline script.

**Fonts (3 faces, 2 mechanisms):**
- **Geist Mono** — npm `geist/font/mono` (`GeistMono.variable` on `<html>` exposes `--font-geist-mono`). Token: `--font-mono: var(--font-geist-mono), ui-monospace, monospace`. Owns all numerics (`.type-num-*`), code (`.type-code`), serials.
- **Inter Local** — `@font-face` in globals.css: `/public/fonts/inter-variable.woff2`, variable weight 100–900, normal, `font-display: swap`. Tokens: `--font-sans` AND `--font-heading` = `"Inter Local", ui-sans-serif, system-ui, sans-serif`. `html { @apply font-sans }`.
- **Redaction 35** — `@font-face`: `/public/fonts/redaction-35-italic.woff2`, italic 400 only, swap. Token `--font-accent: "Redaction 35", ui-serif, Georgia, serif`. Used ONLY by `.type-accent` (the hero accent word).
- **DRIFT (both sides, per fidelity bar):** prose says Space Grotesk, tokens say Inter Local. `lib/el/nav.ts` typography blurb reads verbatim "Two faces only: Space Grotesk for every word, Geist Mono for every number" (with a comment saying the earlier "Geist for every word" was stale and `--font-sans` "is Space Grotesk"); globals.css §Typography comment says "Space Grotesk owns words". The declared token is `"Inter Local"`. Tokens win for rendering (matches memory decision "fonts follow tokens not prose").

**`<body className="min-h-full flex flex-col bg-background text-foreground">`** plus base-layer body rule: `background-image: radial-gradient(120% 90% at 62% 34%, var(--page-glow) 0%, transparent 64%)`, `background-attachment: fixed`, `no-repeat`, `-webkit-font-smoothing: antialiased`. `--page-glow`: light `hsl(240 30% 98%)`, dark `hsl(240 8% 10%)` (page = "deep room" vignette; the falloff reveals `--background`).

**Providers (nesting order):** `ThemeProvider` → `TooltipProvider delayDuration={200}` → children; `Toaster position="bottom-right"` as sibling after children inside ThemeProvider.
- `ThemeProvider` (`components/el/theme-provider.tsx`): next-themes with `attribute="class"`, **`defaultTheme="dark"`**, `enableSystem`, `disableTransitionOnChange` (kills the ~250ms all-element palette smear on toggle).
- `Toaster` (`components/ui/sonner.tsx`): sonner, `theme={resolvedTheme === "light" ? "light" : "dark"}`, className `toaster group`, icons: success=CircleCheck, info=Info, warning=TriangleAlert, error=OctagonX, loading=Loader2 (each `size-4`); `toastOptions.classNames.toast = "cn-toast bloom-cosmic"` — all visual styling lives in globals.css `.cn-toast.cn-toast.cn-toast` (triple class to out-specify sonner's runtime stylesheet).
- `TooltipContent`: portal, `bg-foreground text-background text-xs rounded-md px-3 py-1.5`, max-w-xs, sideOffset 0, 10px rotated-square arrow (`size-2.5 rotate-45 rounded-xs`), animate-in fade-0/zoom-95, per-side slide-in-from-*-2.

**Other global chrome (globals.css `@layer base`):** `* { border-border outline-ring/50 }`; `html` `color-scheme: light` / `html.dark` `color-scheme: dark`; `scroll-padding-block-start: var(--scroll-offset)` (96px); `scroll-behavior: smooth` (forced `auto` under reduced motion); `:focus-visible { outline: 2px solid var(--ring); outline-offset: 2px }`; `::selection` = 35% action mix, foreground text. Native scrollbars: `html`/`.scrollbar-thin` thin, thumb `--border` (hover `--muted-foreground`), 8px, transparent track, pill thumb.
