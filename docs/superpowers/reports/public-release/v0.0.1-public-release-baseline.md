public plugin directory would display verbatim, and the PR template is the first
thing an external contributor reads.

Fold B1 into Task 5 (governance/manifest truth) and extend the guard's corpus in
the same commit, so the wildcard form cannot come back.

## 9. What this audit deliberately did not measure

Stated so that nothing here is mistaken for a verified number:

- **No test counts.** Root, example, CLI, and builder suites were not run. The
  plan reserves the full Flutter ladder for the final gate (Wave C), and running
  it here would buy a number that the next eleven tasks immediately invalidate.
  This report therefore contains **no** test count of its own, and treats the
  counts in `README.md` and `CHANGELOG.md` as unverified prose (B5).
- **No registry rebuild.** The reproducibility diff gate is Wave B. Task 0 is
  required to record the tree without changing it, and the builder writes into
  `registry/generated/`. Only the read-only validator was run (§4).
- **No visual capture.** I2-F4, I2-F9, I2-F10 and the accessibility gap stay
  formally open (§6.3) rather than being closed on a source reading.
- **No package-name reservation.** The pub.dev 404 in §2 is a measurement taken on
  2026-08-24, not a claim that `elattar_cli` will be available at publish time.
