# Elattar 0.0.3

Elattar 0.0.3 publishes the work audited between `v0.0.2` and the pre-release
`main` snapshot: 90 commits in
the complete graph, or 45 commits on the first-parent history once the two
merged feature branches are treated as units.

## Highlights

- A shared `Disabled` wrapper and `disabledReason` contract now cover controls,
  fields, menus, pickers, selection, stats, and agent surfaces.
- `Form.revealFirstError()` and `FormScope` turn a failed submit into a focused,
  visible next step.
- All typography roles resolve mobile, tablet, and desktop steps at the system
  breakpoints. Components and docs consume those roles without local visual or
  motion literals.
- The documentation site has a copyable charts gallery for area, bar, line,
  pie, radar, radial, and tooltip specimens. Pie and radial charts now have
  measured, pointer-following hover tooltips.
- `AgentConsole` integrates history, transcript, composer, attachments,
  downloads, and feature controls. Browser microphone support is implemented
  behind the shipped voice-source interface.
- The documentation shell, navigation, syntax highlighting, README, launch
  material, and CI release reporting were refreshed for public adoption.

## Upgrade

Update the CLI:

```bash
dart install elattar_cli
elattar --version
```

Version 0.0.3 reads the immutable registry at
`https://flutter.elattar.dev/registry/0.0.3/`.

Inspect changes before replacing source you customized:

```bash
elattar add --all --dry-run
```

After saving local customizations, install the 0.0.3 sources:

```bash
elattar add --all --overwrite
elattar doctor
```

The manifest at `.elattar/manifest.json` remains the authority for which files
the CLI installed and where it placed them.

## Migration notes

`AgentConsole.initialAnchor` was removed because history positioning is now
owned by the integrated console. Remove that argument from existing calls.

Disabled controls may now be wrapped by `Disabled` and may expose a
`disabledReason`. Use `FormScope` around a form action when tapping a disabled
submit button should reveal and focus the first invalid field. Use
`onDisabledPressed` only when the disabled action needs a different recovery.

Typography is intentionally responsive across all public roles. Avoid pinning
component copy to local font sizes; use `StyledText` with `TextStyles`, and use
numeric roles for metrics rather than prose roles.

## Registry inventory

The 0.0.3 registry contains 100 items: 98 components, one application block,
and one foundation bundle. Sixty items changed directly and 36 additional
items moved because their dependency closure changed. Four unchanged items
keep their 0.0.1 payloads: `aspect-ratio`, `chart-geometry`, `safe-area`, and
`validation-rule`.

Older release paths remain immutable. `elattar_cli 0.0.1` and `0.0.2` continue
to read their matching registry versions.

## Distribution

The public pub.dev artifact is `elattar_cli 0.0.3`; it installs the design
system as source. The root `elattar_design_system` package remains the
authoritative repository package and is intentionally not published to
pub.dev.

See the complete [changelog](../../CHANGELOG.md), the
[installation guide](https://flutter.elattar.dev/docs/installation), and the
[component gallery](https://flutter.elattar.dev/components).
