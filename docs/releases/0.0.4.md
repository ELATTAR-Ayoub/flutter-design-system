# Elattar 0.0.4

Elattar 0.0.4 publishes one change: the motion vocabulary is fourteen names.

## Highlights

- **Twelve motion recipes, not fifteen plus a scattering of private
  transitions.** `lib/src/components/ui/keyframes.dart` declares `EnterMotion`,
  `ExitMotion`, `OpenMotion`, `CloseMotion`, `ExpandMotion`, `ChangeMotion`,
  `SpinMotion`, `ShimmerMotion`, `ProgressMotion`, `PulseMotion`,
  `CaretMotion` and `SwapRollMotion`. With `Press` and `ActiveIndicator` that
  is the whole vocabulary: fourteen.
- **Every overlay opens on one motion.** `OpenTransition` moved into its own
  file and now plays the dialog, alert dialog, popover, tooltip, hover card,
  menu, context menu, dropdown menu, menubar, combobox and select. Each of
  those had been carrying its own private transition. The sheet and the drawer
  keep their edge slides, which were never vocabulary.
- **One click feel.** `Press` shrinks to `0.9` and no longer takes a `scale`
  argument. `InteractiveCard`, the slider's thumb scales and the button's own
  scale all fold into it.
- **A seven-step duration scale** — `tick`, `fast`, `normal`, `slow`,
  `overlayEnter`, `open`, `bloom` — plus one constant per looping animation or
  surface, plus the third-party behaviour timers that were never animations.
  `MotionCurves` keeps seven curves.
- **Reduced motion is honest on close.** Six overlay controllers set a
  `reverseDuration` and now reassign it wherever they reassign `duration`, so a
  close collapses to a frame instead of running its full length.
- **Matching web vocabulary.** The web design system cut to the same fourteen
  on the same day, so `anim-enter` is `EnterMotion`, `anim-open` is
  `OpenMotion`, and so on down the list.

## Upgrade

Update the CLI:

```bash
dart install elattar_cli
elattar --version
```

Version 0.0.4 reads the immutable registry at
`https://flutter.elattar.dev/registry/0.0.4/`.

Inspect changes before replacing source you customized:

```bash
elattar add --all --dry-run
```

After saving local customizations, install the 0.0.4 sources:

```bash
elattar add --all --overwrite
elattar doctor
```

The manifest at `.elattar/manifest.json` remains the authority for which files
the CLI installed and where it placed them.

## Migration notes

This release removes public API. Every removed name has a replacement, and
[`docs/references/motion-rename.md`](../references/motion-rename.md) is the
complete before-and-after table.

**Motion classes.** `EntranceMotion`, `SpringEntranceMotion`, `FadeUp`,
`RowMotion`, `_PanelIn` and `_FadeIn` become `EnterMotion`.
`StateChangeMotion`, `CheckmarkDrawMotion`, `DashDrawMotion` and
`DotSelectionMotion` become `ChangeMotion`. `LoadingShimmerMotion` becomes
`ShimmerMotion`, `LivePulseMotion` becomes `PulseMotion`,
`ContentSwapMotion` becomes `SwapRollMotion`, and `TextRevealMotion` becomes
`CaretMotion`. `MenuMotion` and the private overlay transitions become
`OpenTransition`. `RevealMotion`, `SweepMotion`, `TravelMotion` and
`DiscreteProgressMotion` are gone: nothing used them.

**`Press.scale` is removed.** Delete the argument. Everything presses at
`MotionTransforms.press` (0.9). `InteractiveCard` is removed; compose
`HoverBuilder` with `Press` instead, and inset your own border if you draw one
with `DecoratedBox`, which does not reserve space for it.

**Tokens.** `MotionDurations.reward`, `popIn`, `springUp`, `signOn`,
`ratchet`, `checkDraw`, `dashDraw`, `dotPop`, `pressSpringUp`,
`copyConfirmation`, `frame`, `overlayExit`, `close`, `collapse` and `expand`
are removed; read the seven-step scale or the recipe that replaced the
animation. `MotionTransforms` keeps `press` and `swapRollTravel`.
`MotionCurves.balanced`, `decelerate`, `symmetric`, `linear` and `vaul` are
removed; use one of the seven, or `Curves.linear`.

**Behaviour that changed on purpose.** A removed history row no longer
animates its own gap closed. The checkbox tick and the radio dot pop rather
than draw themselves on. Switching conversations is an exit followed by an
entrance, not a blur. Slider thumbs and buttons press at 0.9 like everything
else.

## Registry inventory

The 0.0.4 registry contains 100 items: 98 components, one application block,
and one foundation bundle. Ninety-five items moved to 0.0.4, directly or
because their dependency closure changed. `form` keeps its 0.0.3 payload, and
four unchanged items keep their 0.0.1 payloads: `aspect-ratio`,
`chart-geometry`, `safe-area`, and `validation-rule`.

Older release paths remain immutable. `elattar_cli 0.0.1` through `0.0.3`
continue to read their matching registry versions.

## Distribution

The public pub.dev artifact is `elattar_cli 0.0.4`; it installs the design
system as source. The root `elattar_design_system` package remains the
authoritative repository package and is intentionally not published to
pub.dev.

See the complete [changelog](../../CHANGELOG.md), the
[installation guide](https://flutter.elattar.dev/docs/installation), and the
[component gallery](https://flutter.elattar.dev/components).
